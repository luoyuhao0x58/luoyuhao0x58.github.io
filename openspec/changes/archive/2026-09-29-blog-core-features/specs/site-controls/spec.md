## Purpose

统一站级控件（主题切换与语言切换）的交互体验：主题选择跨页面持久化并在 View Transitions 导航后保持一致，主题按钮置于页面底部避免打扰内容阅读，语言切换收敛为下拉形态且无脚本可用。

## ADDED Requirements

### Requirement: 主题选择持久化

系统 SHALL 将用户手动选择的主题（白天/黑夜/自动）持久化到浏览器本地存储，并在页面加载与 View Transitions 导航后应用该选择。导航后页面主题 SHALL 与用户选择一致，且按钮显示的当前状态与真实主题一致。

#### Scenario: 点击切换主题并持久化

- **WHEN** 用户点击主题按钮切换为黑夜主题
- **THEN** 主题立即变为黑夜，选择写入本地存储

#### Scenario: 导航后主题保持一致

- **WHEN** 用户在黑夜主题下访问另一篇文章
- **THEN** 新页面仍为黑夜主题，且按钮显示当前状态为"黑夜"

#### Scenario: 刷新后恢复选择

- **WHEN** 用户刷新页面
- **THEN** 页面恢复其上次手动选择的主题

### Requirement: 主题切换按钮位置

主题切换按钮 SHALL 位于页面底部区域（Footer），不置于顶部导航。

#### Scenario: 底部可见主题按钮

- **WHEN** 查看任意页面底部
- **THEN** 可见主题切换按钮

#### Scenario: 顶部无主题按钮

- **WHEN** 查看任意页面顶部导航
- **THEN** 不出现主题切换按钮

### Requirement: 语言下拉切换

语言切换控件 SHALL 为下拉形态（默认收起、点击展开），而非平铺多个语言链接；SHALL 在禁用 JavaScript 时仍可展开并切换语言。

#### Scenario: 控件为收起下拉

- **WHEN** 访问任一页面
- **THEN** 语言控件为收起状态的下拉，而非多个平铺的语言链接

#### Scenario: 下拉切换语言

- **WHEN** 点击语言下拉并选择目标语言
- **THEN** 跳转到对应语言的同 slug 页面（缺该语言文章时回退该语言首页）

#### Scenario: 禁用 JavaScript 仍可切换

- **WHEN** 浏览器禁用 JavaScript
- **THEN** 语言下拉仍可展开并完成语言切换
